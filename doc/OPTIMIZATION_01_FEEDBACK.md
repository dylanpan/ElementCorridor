# 战斗爽感优化方案一：强化即时反馈

## 概述

本方案聚焦于改动量小、效果立竿见影的视觉与交互反馈增强。核心思路是让玩家的每一次操作——合成、提交订单、连击——都能获得即时的感官回馈，消除当前"静悄悄"的操作体验。

---

## 1.1 合成视觉特效升级

### 现状问题

当前合成只是两个元素消失、一个新元素出现，动画平淡，缺乏视觉冲击力。高等级合成与低等级合成没有任何区别。

### 改进方案

#### 粒子爆散效果

每次合成时，在合成位置生成粒子爆散动画：

| 元素类型 | 粒子颜色 | 粒子数量 |
|----------|----------|----------|
| 火焰 (fire) | #FF6B35, #FF4500 | 8~12 个 |
| 水滴 (water) | #4A90D9, #00BFFF | 8~12 个 |
| 土块 (earth) | #8B6914, #D2691E | 8~12 个 |
| 微风 (air) | #7EC8E3, #E0FFFF | 6~10 个 |
| 植物 (plant) | #4CAF50, #32CD32 | 8~12 个 |

粒子行为：从合成中心向外扩散，0.4秒内逐渐放大并淡出。

#### 等级触发特效

| 合成等级 | 特效 | 表现 |
|----------|------|------|
| Lv.2~3 | 基础粒子 + 轻微缩放脉冲 | 元素图标先缩小再弹回原大小 |
| Lv.4（稀有） | 粒子 + 屏幕边缘闪光 | 白色闪光从四边向中心汇聚，持续0.3秒 |
| Lv.5（史诗） | 粒子 + 全屏闪烁 + 屏幕震动 | 震动幅度5px，持续0.15秒；金色闪烁 |
| Lv.6（传说） | 粒子 + 慢动作 + 光柱 | 游戏暂停0.3秒（慢放），一道光柱从天而降 |

#### 实现方式

在 `BoardRenderer.js` 中新增方法：

```
playMergeEffect(row, col, level, elementType)
```

使用 Canvas 2D 绘制粒子系统，不依赖外部库。粒子数据结构：

```javascript
{
  x, y,           // 当前位置
  vx, vy,         // 速度
  color,          // 颜色
  size,           // 大小
  life,           // 剩余生命 (0~1)
  maxLife,        // 最大生命
}
```

每帧更新粒子位置和透明度，生命归零后移除。

## 1.2 连击计数器常驻显示

### 现状问题

连击只在合成瞬间有文字提示，没有持续的视觉反馈，玩家容易忽略连击的存在。

### 改进方案

#### 连击计数 UI

在屏幕上方（分数条下方）新增连击显示区域：

```
[ 💥 Combo x5 ]  [ ×1.5 ]
  连击次数       积分倍率
```

- 每次合成成功时数字跳动放大（scale 1→1.3→1），持续0.2秒
- 连击中断时红色闪烁 "Combo Break!"，持续0.5秒后消失
- 连击数为0时不显示该区域

#### 连击里程碑特效

| 连击数 | 特效 | 提示文案 |
|--------|------|----------|
| 5 | 棋盘边框短暂亮起绿光 | "🔥 5连击！节奏不错" |
| 10 | 棋盘边框蓝色火焰环绕动画（持续3秒） | "⚡ 10连击！合成大师" |
| 20 | 全屏金色闪光 + 边框闪电特效（持续5秒） | "🌟 20连击！！传说级操作" |

里程碑特效仅在首次达到时触发，之后每次达到相同里程碑只显示文字提示。

#### 实现方式

在 `UIManager.js` 中新增连击显示区域 DOM 元素，通过 EventBus 监听 `combo:updated` 事件更新显示。

## 1.3 订单提交反馈增强

### 现状问题

提交订单时只有分数数字变化，缺少"交付"的满足感。

### 改进方案

#### 消耗元素飞入动画

提交订单时，被消耗的棋盘元素以动画形式飞向订单栏：

1. 元素从棋盘位置缩小并升起
2. 沿弧线飞向订单位置
3. 到达后消散为光点

动画时长：0.3秒/个，多个元素依次执行。

#### 弹跳积分数字

订单提交后，获得的积分数值以弹跳数字形式从订单位置飘出：

- 普通订单（<50分）：白色数字，向上飘移1秒后消失
- 大额订单（50~100分）：金色数字，放大+旋转效果
- 巨额订单（>100分）：金色数字 + 周围星形粒子

#### 订单完成横幅

当提交的订单使关卡进度超过以下阈值时，显示横幅提示：

- 25% — "进度良好！"
- 50% — "已经过半！"
- 75% — "胜利在望！"
- 100% — "目标达成！"

横幅从顶部滑入，停留1.5秒后滑出。

## 1.4 发射器点击反馈

### 现状问题

点击发射器产出元素时，只有元素出现在棋盘上，发射器本身没有反馈。

### 改进方案

- 点击发射器时按钮产生按压动画（下沉→弹起）
- 发射器图标闪烁一次
- 冷却期间按钮半透明 + 旋转的冷却环指示器
- 冷却完成时按钮恢复高亮 + 微光呼吸动画
