# 战斗爽感优化方案二：核心玩法升级

## 概述

本方案聚焦于改变战斗节奏和结构，让每关不再是从头到尾的单调循环，而是有起承转合、有阶段目标、有意外惊喜的完整体验。

---

## 2.1 波次系统（Waves）

### 现状问题

当前每关只有一个目标分数，玩家从头到尾做同一件事，缺乏阶段性成就感和节奏变化。

### 改进方案

将每关拆分为 3~5 个小波次，每个波次有自己的子目标和奖励。

#### 波次结构

```
[进入关卡]
    ↓
[第一波：热身] → 目标: 累计合成 5 次 → 奖励: +50 积分
    ↓
[第二波：限时挑战] → 目标: 30秒内提交 2 个订单 → 奖励: 所有发射器加速 30% 持续 15秒
    ↓
[第三波：精英合成] → 目标: 合成一个 Lv.4+ 元素 → 奖励: 额外获得一个订单槽
    ↓
[最终波：冲刺] → 目标: 达到关卡总分 → Boss规则生效（如有）
    ↓
[通关结算]
```

#### 波次切换表现

每个波次完成时：

1. 屏幕中央出现波次完成提示："✓ 第一波完成！"
2. 奖励以图标+文字形式展示（如 "⚡ 发射器加速 30%"）
3. 短暂停顿（0.5秒）后进入下一波
4. 新波次开始时显示波次标题："⚔️ 第二波：限时挑战"

#### 波次配置数据

在 `gameConfig.js` 或 `rogueConfig.js` 中新增配置：

```javascript
const WAVE_CONFIGS = {
  // 按层数范围定义可用波次模板
  early: [
    { type: 'synthesis', target: 5, label: '合成练习', reward: { type: 'score', value: 50 } },
    { type: 'timed_order', duration: 30, count: 2, label: '急单处理', reward: { type: 'speed_boost', value: 0.3, duration: 15000 } },
  ],
  mid: [
    { type: 'elite_synthesis', minLevel: 4, label: '高级合成', reward: { type: 'extra_order_slot', value: 1 } },
    { type: 'combo_challenge', target: 5, label: '连击挑战', reward: { type: 'score_multiplier', value: 2, duration: 20000 } },
  ],
  late: [
    { type: 'survival', duration: 45, label: '生存模式', reward: { type: 'clear_board' } },
    { type: 'precision', targetLevel: 4, count: 3, label: '精准合成', reward: { type: 'legendary_boon_temp' } },
  ],
};
```

#### 肉鸽模式适配

- 波次类型受当前祝福影响（拥有"连击大师"祝福时更容易刷出连击挑战波次）
- 诅咒会增加波次难度（"缓慢生长"诅咒下限时波次的时限缩短 20%）
- Boss 关的波次数量固定为 2 波：第一波清杂兵，第二波 Boss 战

## 2.2 紧急事件系统

### 现状问题

战斗中没有任何突发状况，玩家可以完全按照自己的节奏操作，缺乏紧张感。

### 改进方案

在战斗过程中随机触发短时事件，打破单调循环。

#### 事件列表

| 事件 | 图标 | 触发条件 | 效果 | 持续时间 |
|------|------|----------|------|----------|
| 紧急订单 | 🎯 | 每关首次提交订单后有 40% 概率触发 | 出现一个限时 15 秒的高额订单（奖励 2~3 倍），倒计时红色闪烁 | 15秒 |
| 元素暴走 | ⚡ | 棋盘空位 < 30% 时有 25% 概率触发 | 所有发射器速度翻倍，棋盘快速填满 | 10秒 |
| 合成风暴 | 💥 | 连击中断时有 30% 概率触发 | 接下来 8 秒内每次合成额外获得双倍积分 | 8秒 |
| 自动整理 | 🧹 | 棋盘空位 < 20% 时有 35% 概率触发 | 自动将所有可合成的相邻元素移到一起 | 瞬间 |
| 元素漩涡 | 🌪 | 每次新波次开始时有 20% 概率触发 | 棋盘上随机两对元素交换位置，可能形成新的可合成对 | 瞬间 |
| 丰收时刻 | 🌾 | 连续 3 次合成成功后触发 | 下一个产出的元素等级 +2 | 单次生效 |
| 积分加倍 | ✖️ | 关卡进度 > 50% 后有 15% 概率触发 | 接下来 10 秒内所有获取积分翻倍 | 10秒 |

#### 事件触发机制

- 每个事件有独立的冷却时间（同事件 60 秒内不重复触发）
- 同一时间最多激活一个事件
- 事件即将发生时屏幕边缘出现预警提示（黄色闪烁箭头）
- 事件开始时屏幕中央弹出横幅："🎯 紧急订单！限时 15 秒！"
- 事件结束时横幅淡出："⏰ 时间到"

#### 肉鸽模式联动

- 某些祝福可以增加有利事件的触发概率
- 某些诅咒会引入负面事件（如"元素混淆"诅咒增加"混乱漩涡"事件——随机打乱棋盘）
- 祝福"需求预见"可以让紧急订单的时限延长至 25 秒

## 2.3 评分与评级系统

### 现状问题

通关就是"过了"，没有评价、没有重玩动力，玩家打完就结束了。

### 改进方案

每关结束后按多维度评级，给予差异化奖励。

#### 评级维度

| 维度 | 计算方式 | S级条件 | A级条件 | B级条件 |
|------|----------|---------|---------|---------|
| 速度 (Speed) | 通关用时 | < 60秒 | < 90秒 | < 120秒 |
| 连击 (Combo) | 最高连击数 | ≥ 15 | ≥ 10 | ≥ 5 |
| 效率 (Efficiency) | 总积分 / 总操作次数 | ≥ 8 | ≥ 5 | ≥ 3 |
| 合成 (Merge) | 最高合成等级 | Lv.6 | Lv.5 | Lv.4 |

#### 综合评级

| 评级 | 条件 | 星尘奖励倍率 | 额外效果 |
|------|------|-------------|----------|
| S | 至少 3 个维度达到 S | ×3 | 下次祝福选择 +1 个选项 |
| A | 至少 2 个维度达到 A | ×2 | 无 |
| B | 至少 2 个维度达到 B | ×1.5 | 无 |
| C | 其余情况 | ×1 | 无 |

#### 结算界面展示

通关后弹出评级面板：

```
╔══════════════════════════╗
║       🏆 关卡结算        ║
║                          ║
║     综合评级: [ S ]       ║  ← 金色闪烁动画
║                          ║
║  速度     ⏱ 45秒  [S]   ║
║  连击     💥 18次  [S]   ║
║  效率     📊 7.2   [A]   ║
║  合成     🔮 Lv.6  [S]   ║
║                          ║
║  星尘奖励: ★★★★★ (×3)   ║
║                          ║
║  [ 继续冒险 ]            ║
╚══════════════════════════╝
```

评级 S 时背景金色粒子飘落，评级 A 时银色，B/C 时标准样式。

#### 历史记录

在 MetaProgress 中记录每次通关的评级数据：

```javascript
bestiary: {
  // ... 现有字段
  ratings: {
    bestRating: 'S',    // 历史最佳评级
    ratingCounts: { S: 3, A: 5, B: 2, C: 0 },
    fastestClear: 42,   // 最快通关秒数
    highestCombo: 22,   // 历史最高连击
  },
}
```

在主菜单显示最佳评级徽章，激励玩家反复挑战。

## 实现优先级

| 序号 | 功能 | 预估工作量 | 效果 |
|------|------|------------|------|
| 1 | 紧急事件系统 | 中 | 高（立即打破单调感） |
| 2 | 波次系统 | 大 | 高（重构关卡流程） |
| 3 | 评分评级 | 中 | 中（提供重玩动力） |
| 4 | 历史记录 | 小 | 中 |

建议先实现紧急事件系统（改动量相对小，效果立竿见影），再实现波次系统和评分评级。
