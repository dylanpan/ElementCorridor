# 元素合成 · 肉鸽融合 —— 玩法深度扩展方案

## 方案概述

在现有「合成+订单提交」核心循环基础上，融入 Roguelike 的随机生成、永久死亡、局内成长和决策分支等核心特征，将原本线性的三关流程改造为具有高重复可玩性的肉鸽爬塔模式。

### 核心理念

> 每一次开局都是一次全新的冒险——随机的祝福组合、变化的订单需求、逐步升级的挑战，直到倒下或登顶。

## 二、核心玩法循环

### 2.1 爬塔结构

```
地面（第0层）           →   第1层    →   第2层    →   ...   →   第N层（Boss）
  │                           │            │                      │
  ├─ 选择初始祝福              ├─ 战斗关     ├─ 战斗关               ├─ Boss战
  ├─ 选择初始发射器            ├─ 祝福关     ├─ 祝福关               ├─ 最终奖励
  └─ 了解本局特殊规则          ├─ 商店关     ├─ 商店关
                               ├─ 事件关     ├─ 事件关
                               └─ 休息关     └─ 休息关
```

每一层包含 2-3 个节点，玩家走格子选择路线。每个节点是一种关卡类型。

### 2.2 关卡类型

| 类型 | 说明 | 胜利条件 | 奖励 |
| --- | --- | --- | --- |
| **战斗关** ⚔️ | 标准合成关卡，有目标分数 | 达到目标分数 | 金币 + 一次祝福三选一 |
| **精英战斗关** 💀 | 更高目标分数 + 负面规则 | 达到目标分数 | 大量金币 + 稀有祝福三选一 |
| **Boss关** 👑 | 极高目标分数 + 特殊限制 | 达到目标分数 | 大量金币 + 传说祝福 + 进入下一层 |
| **祝福关** ✨ | 直接三选一祝福 | 无需战斗 | 一个祝福 |
| **商店关** 🏪 | 消耗金币购买祝福/道具 | 无需战斗 | 消耗金币 |
| **事件关** ❓ | 随机事件，二选一抉择 | 做出选择 | 取决于选择 |
| **休息关** 🏕️ | 恢复或调整 | 无需战斗 | 清空棋盘/恢复发射器 |

### 2.3 单局流程

```
开始新冒险
  ↓
选择初始祝福（3选1）
  ↓
选择初始发射器阵容
  ↓
进入第1层 → 选择路线 → 依次通过节点
  ↓
进入第2层 → ...
  ↓
...
  ↓
到达Boss层 → 击败Boss → 通关结算
  ↓
（若中途棋盘满则冒险结束，获得局外货币）
```

## 三、祝福系统（Boon System）

这是肉鸽玩法的核心策略维度。祝福是对玩家能力的永久性（本局内）强化，通过叠加产生丰富的 Build 流派。

### 3.1 祝福分类

#### 产出类祝福（影响发射器）

| 祝福名称 | 效果 | 稀有度 |
| --- | --- | --- |
| 加速齿轮 | 所有发射器冷却时间减少 20% | 普通 |
| 双重产出 | 发射器有 30% 概率一次产出两个元素 | 稀有 |
| 高级起步 | 发射器产出的元素初始等级 +1 | 稀有 |
| 元素亲和·火 | 火焰发射器冷却减半 | 普通 |
| 元素亲和·水 | 水滴发射器冷却减半 | 普通 |
| 元素亲和·土 | 土块发射器冷却减半 | 普通 |
| 元素亲和·风 | 微风发射器冷却减半 | 普通 |
| 元素亲和·植物 | 植物发射器冷却减半 | 普通 |
| 无尽之泉 | 每完成一个订单，所有发射器立即冷却完毕 | 传说 |
| 变异孢子 | 发射器有 15% 概率产出高一级的元素 | 史诗 |

#### 合成类祝福（影响 Merge）

| 祝福名称 | 效果 | 稀有度 |
| --- | --- | --- |
| 连击大师 | 连击窗口延长至 5 秒 | 普通 |
| 连锁反应 | 合成后有 20% 概率在原地再生成一个低一级的同类型元素 | 稀有 |
| 融合增效 | 合成时额外获得 1 积分 | 普通 |
| 超量合成 | 合成 Lv.4 以上元素时，有 30% 概率不消耗其中一个 | 史诗 |
| 元素共鸣 | 合成时，棋盘上所有同类型元素等级临时 +1（仅视觉） | 传说 |
| 三重奏 | 三个同类型同等级元素可合成（替代原有的两两合成） | 稀有 |
| 经验累积 | 每次合成获得该元素等级 ×2 的额外积分 | 普通 |

#### 订单类祝福（影响 Order）

| 祝福名称 | 效果 | 稀有度 |
| --- | --- | --- |
| 急单奖励 | 订单积分奖励增加 30% | 普通 |
| 批量交付 | 提交订单时不消耗元素，改为标记（标记后不可再次提交同一元素） | 史诗 |
| 订单刷新免费 | 刷新订单不消耗积分 | 稀有 |
| 需求预见 | 始终多显示一个订单 | 普通 |
| 高价收购 | 每关第一个提交的订单获得 3 倍积分 | 稀有 |
| 以物易物 | 可以消耗 2 个任意元素代替订单需求的元素 | 传说 |

#### 棋盘类祝福（影响 Board）

| 祝福名称 | 效果 | 稀有度 |
| --- | --- | --- |
| 扩容背包 | 棋盘增加一行（+列数个格子） | 稀有 |
| 紧凑布局 | 棋盘减少一列但增加两行（总格子数不变） | 普通 |
| 自动整理 | 每 10 秒自动将棋盘上的可合成元素移到相邻位置 | 史诗 |
| 守护结界 | 棋盘满时，自动销毁最低级元素腾出 1 个空位（每关 3 次） | 稀有 |

### 3.2 祝福叠加规则

- 同类祝福加法叠加（如两个「加速齿轮」= 冷却减少 40%）
- 不同类祝福乘法叠加（如「加速齿轮」×「元素亲和·火」= 0.8 × 0.5 = 冷却减少 60%）
- 同名祝福不可重复获取
- 祝福上限：最多持有 8 个祝福，超过时需要替换已有祝福

### 3.3 诅咒系统

作为高风险高回报的选择，诅咒是带有负面效果的"祝福"：

| 诅咒名称 | 负面效果 | 补偿增益 |
| --- | --- | --- |
| 缓慢生长 | 所有发射器冷却时间 +30% | 订单积分 +50% |
| 元素混淆 | 发射器随机产出元素类型（不固定） | 棋盘扩大 2 格 |
| 贪婪代价 | 每次提交订单额外消耗 1 个随机元素 | 订单积分翻倍 |
| 时间紧迫 | 每关限时 60 秒 | 所有祝福稀有度提升一级 |
| 脆弱棋盘 | 棋盘缩小 4 格 | 初始获得一个传说祝福 |

**Emitter 改造** —— 支持祝福注入：

```javascript
class Emitter {
  constructor(config) {
    // ... 原有属性
    this.modifiers = {
      cooldownMultiplier: 1.0,
      spawnCount: 1,
      spawnLevelBonus: 0,
      elementOverride: null,
    };
  }
  
  /** 应用祝福修饰器 */
  applyModifiers(mods) {
    Object.assign(this.modifiers, mods);
  }
  
  /** 重写 spawn 方法支持多重产出 */
  spawn(currentTime) {
    if (!this.isReadyToSpawn(currentTime)) return null;
    this.lastSpawnTime = currentTime;
    this.totalSpawns++;
    
    const elements = [];
    const count = this.modifiers.spawnCount;
    for (let i = 0; i < count; i++) {
      const level = this.spawnLevel + this.modifiers.spawnLevelBonus;
      const type = this.modifiers.elementOverride || this.elementType;
      elements.push(new Element(type, Math.min(level, ELEMENT_LEVELS.length)));
    }
    return elements; // 改为返回数组
  }
}
```

## 九、平衡性设计要点

### 9.1 难度曲线公式

```
第 N 层目标分数 = 基础分数 × (1.15 ^ (N - 1))
第 N 层订单难度权重 = 基础权重 + N × 0.05（向高难度偏移）
Boss 层目标分数 = 普通层 × 1.8
```

### 9.2 祝福强度控制

- 普通祝福：约 15-25% 的提升幅度
- 稀有祝福：约 30-50% 的提升幅度，附带条件
- 史诗祝福：约 60-80% 的提升幅度，有明显副作用或条件
- 传说祝福：100%+ 的提升幅度，改变游戏规则

### 9.3 经济平衡

- 战斗关基础金币奖励：10 + 层数 × 3
- 精英战斗关：基础奖励 × 2
- 商店祝福价格：普通 20G / 稀有 40G / 史诗 70G / 传说 120G
- 金币不能继承到下一局

### 10.2 推荐开发顺序

1. 先跑通 **RogueSystem 状态机**（纯逻辑，可单元测试）
2. 再接入 **BoonSystem** 并验证祝福效果能正确影响游戏数据
3. 然后做 **UI 层**（看到效果才有动力继续）
4. 接着补 **事件系统** 和 **Boss 战**
5. 最后做 **局外成长** 作为长线留存

### 10.3 与 Godot 迁移的兼容性

本次扩展的所有新增模块遵循与原项目相同的分层原则：

- `systems/` 目录下的纯逻辑代码（RogueSystem、BoonSystem、EventSystem、MetaProgress）不依赖 DOM
- `ui/RogueUIManager.js` 是唯一的 DOM 耦合模块
- 迁移至 Godot 时，逻辑层代码可直接复用，仅需重写 UI 层
